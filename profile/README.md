# Privatus Analytics

Privacy-first, cookieless web analytics. No cookie banner needed.

This organization hosts our integrations and open-source clients: plugins for WordPress, Drupal, Craft, Framer, Wix, Shopify and Netlify, apps for Zapier, Make, n8n, Pipedream and Stripe, the CLI, the Terraform provider and the JavaScript packages.
